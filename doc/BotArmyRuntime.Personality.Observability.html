    BotArmyRuntime.Personality.Observability (bot_army_runtime v0.9.9)

    Copy Markdown

    Telemetry and structured logging for soul (tenant DB) and pulse (NATS) paths.

    Telemetry event names

    All use the [:bot_army, :personality, ...] prefix for PromEx and ad-hoc handlers.

    EventMeasurementsMetadata
    [:bot_army, :personality, :soul, :get]duration (native), countoutcome, bot_id, tenant_id, optional soul_version
    [:bot_army, :personality, :soul, :upsert]duration (native), countoutcome, bot_id, tenant_id, optional soul_version
    [:bot_army, :personality, :soul, :publish]countoutcome, bot_id, tenant_id, optional error
    [:bot_army, :personality, :pulse, :publish]countoutcome, bot_id, tenant_id, subject, optional error

    Attach handlers with :telemetry.attach/4 or scrape via BotArmyRuntime.Metrics.PromExPlugin.
