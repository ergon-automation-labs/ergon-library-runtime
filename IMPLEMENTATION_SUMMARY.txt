NEXT STEPS FOR SERVICES

To use bot_army_runtime in a service (e.g., bot_army_gtd):

1. Add to mix.exs:
   {:bot_army_runtime, path: "../bot_army_runtime"}

2. Create service-specific Repo:
   defmodule BotArmyGTD.Repo do
     use BotArmyRuntime.Ecto.Repo
   end

3. Configure in config.exs:
   config :bot_army_gtd, BotArmyGTD.Repo,
     database: "bot_army_gtd_dev"

4. Use in services:
   BotArmyRuntime.NATS.Publisher.publish("subject", payload)
   result = BotArmyGTD.Repo.all(Schema)
